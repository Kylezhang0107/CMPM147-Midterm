# 🐱 Procedural Cat Character Generator

A procedural generator that creates unique cat characters for use in games, stories, or simulation systems. The tool generates cats with different combinations of traits such as personality, appearance, behavior quirks, backstory, and needs.

## Features

- **Procedural Generation**: Creates unique cat NPCs with randomized traits
- **Comprehensive Traits**: Each cat includes:
  - Name (from a pool of 46 cat names)
  - Appearance (size, color, patterns, and distinctive features)
  - Personality (3 unique personality traits)
  - Habits (3 behavioral quirks)
  - Likes (3-4 preferences)
  - Dislikes (2-3 aversions)
  - Backstory (procedurally generated narrative)
- **Generation History**: Track recently generated cats
- **Beautiful UI**: Modern, responsive interface with smooth animations

## How to Use

1. Open `index.html` in a web browser
2. Click the "Generate Cat Character" button
3. View your unique cat character with all its traits
4. Generate as many cats as you need - each one is unique!

## Technical Details

- **Pure JavaScript**: No external dependencies required
- **Extensive Data Pools**: 
  - 46 names
  - 5 size categories
  - 15 color variations
  - 11 pattern types
  - 16 distinctive features
  - 24 personality traits
  - 21 behavioral habits
  - 24 likes
  - 24 dislikes
  - Multiple backstory components
- **Smart Randomization**: Ensures unique combinations without repetition within a generation
